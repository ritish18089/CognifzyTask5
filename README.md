# TaskMaster - Advanced CRUD Operations

A professional, responsive, and modern Task Management Application built using HTML5, CSS3, and Vanilla JavaScript (ES6+).

## Features
- **Create, Read, Update, Delete (CRUD)** tasks.
- **Persistent Storage** using browser LocalStorage.
- **Search, Filter, and Sort** capabilities.
- **Dashboard Statistics** updating dynamically.
- **Import / Export** task data in JSON format.
- **Light & Dark Mode** theming (persisted).
- **Responsive UI** (Glassmorphism design, mobile friendly).
- **Toast Notifications** and **Modal Confirmations**.
- **Input Validations** to prevent bad data.

## Project Structure
- `index.html`: Main view
- `css/`: Styling with Glassmorphism, Animations, and Responsiveness.
- `js/`: Modular ES6 scripts (App, UI, Storage, TaskManager, Validation, Filters, Statistics, Export/Import, Notifications).

## Setup
Simply open `index.html` in any modern web browser or serve via a local development server (e.g., Live Server extension in VS Code).

## Requirements Addressed
- Strict Folder naming (`Task 5-Advanced CRUD Operations`).
- Advanced DOM manipulation and ES6 standards (Modules, Classes, Arrow Functions, Array Methods).
- Complete styling without external heavy libraries (except FontAwesome for icons).
